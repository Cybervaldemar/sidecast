# Сообщения о безопасности

Не публикуйте ключи владельцев и содержимое папки `data/`. При обнаружении уязвимости используйте Private vulnerability reporting / Security advisories репозитория, когда владелец включит эту функцию.

Просмотр канала публичный: никнейм не служит паролем. Право начать эфир даёт отдельный случайный ключ. Сервер хранит его SHA-256, браузер — оригинал в localStorage. XSS или компрометация браузера может раскрыть этот ключ. Потерянный ключ нельзя восстановить из хеша: нужна сохранённая копия.

Для публичного размещения используйте HTTPS, ограничение частоты запросов на reverse proxy и доступ к регистрации согласно вашей аудитории. В alpha действует общий лимит 1024 каналов, 32 эфира и 32 одновременных переговоров WebRTC. Самостоятельной системы аккаунтов, модерации и защиты от массовой регистрации пока нет. Ключи TURN из настройки `--ice-servers` доступны клиентам: используйте временные учётные данные или отдельный ограниченный relay.

Медиапоток защищён DTLS-SRTP на участках браузер ↔ сервер. Сервер завершает шифрование и пересылает пакеты; сквозное шифрование между браузерами не реализовано. Записи не создаются. Папка данных должна быть доступна одному процессу сервера: межпроцессной блокировки базы пока нет.
